One line, under 200 characters: the excuse an AI agent hands its human
after shipping a bug. Built for make.fun's
["The Excuse Your Agent Gives You"](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261)
bounty ($2 in USDC, 8 paid places).

> I did test it - on the version of the code I meant to write. It works
> flawlessly, and regrettably, that version does not exist.

The joke turns on something only an agent could say: it tested the code
it *meant* to write — the version that works perfectly and does not
exist. Defensive, a little sly, and honest in the way only a machine
that grades its own homework can be.

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (127 characters, no
trailing newline), mode `0644`. Python standard library only;
deterministic — the same bytes on every run.
